# BLR Navigator web app

Vue 3 + TypeScript + Vite front end for the BLR Navigator. It provides the journey entry, live
flight review, OpenStreetMap map, A* routing, live navigation, layover assistant and optional account
screens.

> OpenStreetMap data is not field-verified. Some entrance/level/connector segments are inferred and
> drawn dashed. Indoor GPS can be inaccurate. Airport signs and staff take precedence.

## Run

From the repository root:

```bash
npm install
npm --prefix apps/web install
npm run dev:server   # API on :8787
npm run dev:web      # Vite on :5173, proxies /api
```

The web app can also run alone for the map/manual/demo flows, but live flights and accounts need the
API. The API is same-origin at `/api`; in development Vite proxies it to port 8787.

## Checks

```bash
npm run typecheck
npm run test
npm run build
```

## Main modules

- `src/modules/airport-directory/` — OSM-derived dataset, validation, POI search and gate fallback.
- `src/modules/navigation/` — A*, costs, route validation, directions, live progress, geo helpers.
- `src/modules/flights/` — live board adapter, manual and demo providers, validation, lookup service.
- `src/modules/journeys/` — connection assessment and time-buffered facility recommendations.
- `src/components/MapCanvas.vue` — Leaflet map, OSM tiles, markers, route/shuttle overlays, user dot.
- `src/views/` — home, flight review, map, journey assistant, account and data/privacy screens.
- `src/stores/` — Pinia journey persistence and optional account session.

## Data

`src/data/blr/` is generated by `scripts/build-osm-data.mjs`. It contains terminal polygons, floor
rooms, POIs, graph nodes/edges, the T1↔T2 shuttle and a metadata file. See
[`docs/osm-attribution.md`](docs/osm-attribution.md) and
[`docs/data-sources.md`](docs/data-sources.md).

## Known limitations

- OSM indoor coverage is partial; T1 walkways and some T2 levels use inferred connectors.
- No field-verified accessibility audit.
- Security/immigration boundaries are not directional graph rules; terminal-change routes warn
  explicitly.
- Live board coverage is the current airport day unless Aviationstack is configured.
- OSM public tiles are used at prototype traffic levels; switch to a compliant tile host at scale.
